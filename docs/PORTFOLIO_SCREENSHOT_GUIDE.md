# Portfolio Screenshot Guide — NBA Playoff Companion AI

## Enable Screenshot Mode

1. Sidebar → **Portfolio Screenshot Mode**
2. Select a playoff team (e.g., New York Knicks)
3. Stay on **Home Dashboard**
